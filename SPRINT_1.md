VittaCare — Sprint 1: Caso de Uso Agendar Consulta
Bloco 8 — Documentação para Desenvolvimento

A Sprint será baseada no caso de uso UC01 — Agendar Consulta, uma das principais funcionalidades do VittaCare.
Informação	Definição
Sprint	01
Duração	2 semanas (10 dias úteis)
Ator principal	Paciente
Objetivo	Planejar o fluxo de agendamento de consultas
Prioridade	Alta
Entrega	Protótipo, requisitos, contrato de API e critérios de aceite

História de usuário
Como paciente, quero selecionar uma especialidade, escolher um profissional e reservar um horário disponível para conseguir agendar minha consulta de forma simples e organizada.

Critérios de aceite
- O paciente deverá estar autenticado.
- O sistema deverá apresentar especialidades e profissionais disponíveis.
- O paciente deverá conseguir selecionar uma data e um horário livre.
- O sistema deverá impedir conflitos de agendamento.
- A confirmação deverá apresentar os dados da consulta.
- O agendamento deverá aparecer em Minhas Consultas.
  
Planejamento das atividades
Atividade	Período
Levantamento dos requisitos	Dias 1–2
Modelagem do caso de uso	Dias 3–4
Protótipos das telas	Dias 5–6
Contrato de API e dados	Dias 7–8
Revisão e validação	Dias 9–10
